## 开发注意事项

### 需考虑系统版本兼容性

有的客户系统版本比较老，比如政府单位的系统，他们为了稳定不愿意升级系统版本，可能用的还是19KB版本的系统，像这样比较老的版本你就可要小心，很可能会造成不兼容问题，会导致导入的开发在客户环境上不兼容，客户环境会缺少依赖，或者缺少系统功能。

#### 检查开发依赖

客户环境可能缺少依赖 jar 包，或者 jar 包版本太低，可写一个 jsp 文件去检查环境依赖，校验开发所需要的依赖是否在客户环境中存在，JSP 文件可由 AI 编写，将 JSP 文件放入客户服务器中，然后在浏览器执行。

#### 检查系统功能

如果开发依赖某些系统功能，比如 ESB，流程表单页面PDF生成功能，如果系统版本太老，甚至是连 ecode 页面都没有。如果客户系统版本比较老（如 kb19 版本），在开发之前应确认涉及的标准功能是否存在。
